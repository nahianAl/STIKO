# SolidWorks assemblies (.sldasm) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `.sldasm` uploaded on its own converts to a GLB on the existing CAD worker and opens in the 3D viewer, with every component listed by its real name in the parts panel.

**Architecture:**
- **Worker:** `sldasm` joins the worker's `CAD_EXTENSIONS`. The converter rebuilds the assembly from the display copy SolidWorks stores inside the file.
- **Naming:** `usd_to_glb.py` names each glTF node after the nearest enclosing USD prim's `displayName`, for every format.
- **App:** `sldasm` joins `CAD_CONVERSION_FORMATS` with the new noun `assembly`. Everything else (switch, routes, viewer, units) already follows the table.

**Tech Stack:** Next.js 14 + TypeScript (`node --test`); Python 3.12 + usd-core 26.8 + numpy + pytest (`cad-worker/`); Modal T4 with NVIDIA `usd-convert-cad==0.3.0`.

**Spec:** `docs/superpowers/specs/2026-11-19-sldasm-design.md`. Read it first. It builds on `docs/superpowers/specs/2026-11-19-more-cad-formats-design.md`.

# Body names in the GLB come from the nearest prim with a displayName (usd-convert-cad writes SolidWorks's
# component instance names there, e.g. 'ZINC PLATED STEEL HEX NUT-3'); the parts panel shows them.
MAX_NAME = 120


def body_name(prim):
    """The cleaned displayName of the prim or its nearest named ancestor, or None."""
    p = prim
    while p and p.IsValid() and not p.IsPseudoRoot():
        name = ' '.join(str(p.GetDisplayName() or '').split())[:MAX_NAME]
        if name:
            return name
        p = p.GetParent()
    return None
